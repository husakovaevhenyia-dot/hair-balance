# Hair Balance

Самостійний статичний лендинг Good Hair, System 4, ORising та Eliokap.

Продавець: ФОП Гусакова Євгенія Сергіївна.

## Публікація

HTML/CSS/JavaScript без збірки й залежностей. GitHub Pages: main, коренева папка.
Файл CNAME додається лише після отримання нового домену від власника.
Для перегляду: `python3 -m http.server 4183 --bind 127.0.0.1`.

## Поведінка

Каталог: 22 засоби — 4 Good Hair, 12 System 4, 3 ORising та 3 Eliokap. Пошук, комбіновані фільтри,
деталі товару, вибір товару в заявці, перевірка полів, підготовка листа і копіювання.
Форма не надсилає дані автоматично: відвідувач сам відправляє підготовлений лист.
Аналітики, рекламних трекерів і збереження даних форми в localStorage немає.
Реквізити наведені з даних власника. Адресу з реєстраційної виписки на сайті не опубліковано: документ надано для реєстратора домену.
Назви й об’єми ORising та Eliokap — з наданих власником прайсів. Ціни всіх засобів — за запитом.
Оптові ціни та собівартість процедур не публікуються.
Описи доповнено за матеріалами orising.ua та виробника Solaria (solariaverona.it).
Фотографії ORising — orising.ua, фотографії Eliokap — каталог olаut.com.
Торгові марки та фотографії належать відповідним правовласникам.
